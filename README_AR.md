# سِراج — رفيق التعلّم

تطبيق أندرويد أولي للمعلم والطلاب في الصف الثاني الأساسي، وفق المنهاج السوري.

## المزايا الحالية
- واجهة عربية باتجاه من اليمين إلى اليسار.
- تبديل بين وضع الطالب ووضع المعلم.
- بطاقات أولية للغة العربية والرياضيات والألعاب والإنجازات.
- بطاقات أولية لتحضير الدروس ومتابعة الطلاب والاختبارات والأنشطة.
- يعمل هذا النموذج الأولي دون إنترنت.

## البناء
يتطلب Android SDK 35 وJDK 17 وGradle 8.9.
